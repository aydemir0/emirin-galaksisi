# Emir's Galaxy

Interactive 3D portfolio built as a navigable solar-system experience.

## Overview
An interactive 3D portfolio where projects and skills are represented spatially in a navigable solar-system environment.

## Core Experience
- Interactive solar-system navigation
- Project planets
- Camera transitions
- Spatial project exploration
- Spaceship / warp interaction
- Dynamic blog powered by Firebase
- Responsive 3D behavior

## Architecture / Tech Stack
- Next.js
- React
- React Three Fiber
- Three.js
- Firebase
- TypeScript
- Tailwind CSS

## Engineering Highlights
- 3D scene organization and component architecture
- Camera interaction and dynamic field of view adjustments
- Performance considerations (lazy loading, frustum culling, shader preloading)
- Responsive WebGL behavior adjusting to screen size
- Firebase-backed dynamic content fetching for blog posts


## Local Development
```bash
git clone https://github.com/aydemir0/emirin-galaksisi.git
cd emirin-galaksisi
npm install
npm run dev
```
