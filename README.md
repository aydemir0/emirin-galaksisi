## 🌌 Features
*   **🪐 Interactive 3D Solar System:** Projects are represented by beautifully textured NASA planets (Earth, Mars, Jupiter, Venus) orbiting the Sun. Click to zoom in and view project details in a holographic UI.
*   **🛸 The Odyssey Warp Drive (Easter Egg):** Find the wandering spaceship, click it, and experience a cinematic 10x speed Hyperdrive warp that opens the "Captain's Log" (About Me) Pilot HUD.
*   **📚 Dynamic Star Cluster Blog:** A glowing star cluster fetches real-time tech articles (Frontend, Backend, AI) from Firebase Firestore.
*   **⚡ WebGL Performance Optimized:** Engineered to run smoothly at 60FPS. Features lazy loading, frustum culling, shader preloading, dropping initial load times and stuttering drastically.
*   **📱 Fully Responsive:** The 3D camera and Field of View (FOV) automatically adapt to mobile screens for a perfect touch experience.

## 🛠️ Installation & Setup

Want to run your own galaxy locally?

```bash
# 1. Clone the repository
git clone https://github.com/aydemir0/portfolyo-galaksi.git

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
Navigate to `http://localhost:3000` to start exploring.
